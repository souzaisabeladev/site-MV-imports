## 📱 Sobre o Projeto

O **MV Imports** é uma aplicação web voltada para o segmento comercial/e-commerce. O projeto foi desenhado para oferecer uma vitrine virtual intuitiva, permitindo que os clientes naveguem pelos produtos com facilidade, visualizem destaques e tenham uma experiência fluida tanto no desktop quanto no celular.

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica e organizada de todas as seções do e-commerce.
* **CSS3:** Design responsivo, paleta de cores moderna, estilização dos cards de produtos e layout intuitivo.
* **JavaScript:** Lógica de navegação, dinamismo nos elementos da loja e interatividade com o usuário.
